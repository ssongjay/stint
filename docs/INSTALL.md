# 설치와 두 기기 연결

## Mac

Stint.app을 실행하면 준비한 개인 서버로 연결한다. 창을 닫으면 메뉴바에 남고,
메뉴바에서 다시 열거나 앱을 종료할 수 있다.

1.1.0부터 타이머 오른쪽의 `오빗 링 ⌄` 또는 `모래시계 ⌄`를 눌러 모양을
선택한다. 반접힘 화면에서는 아래쪽 조작 영역에 있다. 선택은 기기마다 기억한다.
두 모양 모두 60분 기준이며 실제 집중·휴식 시간은 주제 설정을 따른다.

상단 동기화 배지를 눌러 연결 설정을 연다. 서버 주소와 연결 키를 복사해
자기 Android 기기에 입력한다. 연결 키를 아는 기기는 기록을 읽고 바꿀 수 있다.

## Android / Galaxy Z Fold8

개인 설치 APK를 설치하고 실행한다. Mac 연결 설정에서 복사한 서버 주소와
연결 키를 넣고 연결한다. 서버 주소는 HTTPS를 사용한다. 알림 권한을 허용하면
진행 중 집중/휴식 시간을 시스템 알림에서도 볼 수 있다.

- 접힌 화면: 한 손 조작용 한 칼럼.
- 펼친 화면: 타이머와 오늘 기록을 나란히.
- 가로 반접힘: 위쪽 타이머, 아래쪽 조작과 기록.
- 접기·펼치기·회전: 타이머 연결과 화면 선택값을 유지.

이 프로젝트는 Google Play 배포가 아니라 개인 설치용 빌드다.

## 개발용 실행

README의 독립 MySQL과 dev.py 실행 방법을 따른다. 실제 서비스 연결 키는
.local/production.json, 개발용 연결 정보는 .local/dev.json에 따로 보관하며
둘 다 Git과 배포 묶음에서 제외한다. 키를 APK에 넣지 않는다.

## USB로 직접 설치한 폰

2026-10-29 실제 Galaxy Z Fold8(SM-F971N, Android 17 / One UI 9)에 설치했다.
USB 디버깅을 사용자가 허용한 뒤 APK를 다운로드 폴더에 복사하고 설치했다.
개인 설치용 debug 빌드는 앱 내부의 고정 임시 연결 파일을 한 번 읽고, HTTPS 주소와
키를 검증한 뒤 Android Keystore로 저장하고 임시 파일을 지운다. release 빌드는
이 파일을 읽거나 적용하지 않는다. 키를 APK나 다운로드 폴더에 넣지 않는다.

이번 폰은 연결을 이미 마쳤으므로 다시 주소나 키를 입력할 필요가 없다.
매번 USB를 연결할 필요 없이 인터넷 연결로 맥과 최신 상태를 공유한다.
다른 폰을 수동 연결할 때는 위의 Mac 연결 설정 화면에서 주소와 키를 복사한다.
