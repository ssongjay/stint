# 설치와 기기 연결

## 서버 준비

Stint 서버는 MySQL에 연결하고 loopback 주소에 바인딩한 뒤 HTTPS reverse proxy
뒤에서 제공한다. 다음 값은 환경변수나 권한이 제한된 별도 설정 파일로 전달한다.

- `STINT_DB_URL`, `STINT_DB_USER`, `STINT_DB_PASSWORD`
- `STINT_AUTH_TOKEN`: 24자 이상의 임의 연결 키
- `STINT_HOST`, `STINT_PORT`

연결 키와 DB 비밀번호를 Git, 일반 설정 JSON, APK 또는 배포 묶음에 넣지 않는다.

## macOS

`Stint.app`을 실행하고 연결 화면에서 HTTPS 서버 주소와 연결 키를 입력한다.
창을 닫으면 메뉴바에 남으며 메뉴에서 다시 열거나 앱을 종료할 수 있다.
메뉴바의 작은 진행 링과 숫자로 남은 시간을 확인한다. 스톱워치는 경과 시간을
보여준다. 메뉴바를 누르면 현재 주제와 60분 기준 원형 시계가 있는 작은 창이 열린다.
작은 창에서 집중 시작·일시정지·계속하기·집중 마치기·휴식 건너뛰기를 할 수 있다.
빈 곳을 누르거나 Esc를 누르면 닫힌다. `Stint 열기`는 전체 작업대를 연다.
굵은 14pt 숫자와 큰 상태 아이콘을 사용하며 메뉴바 배경에 맞춰 표시 색이 바뀐다.
오프라인·동기화 중에는 메뉴바의 시간을 숨기고 작은 창의 제어를 비활성화한다.
상단 동기화 배지를 누르면 현재 연결 정보를 확인할 수 있다. 다른 개인 기기에
같은 서버 주소와 연결 키를 입력하면 현재 타이머와 기록을 공유한다.

## Android

debug APK를 직접 설치하거나 배포 채널에 맞게 서명한 APK를 설치한다. 연결 화면에서
macOS와 같은 HTTPS 서버 주소와 연결 키를 입력한다. 알림 권한을 허용하면
진행 중인 집중·휴식 시간을 시스템 알림에서도 볼 수 있다.

실행 중인 타이머는 지원되는 Android에서 상단 실시간 타이머 칩과 Galaxy Now Bar
표시를 요청한다. 실제 노출은 기기·알림 설정에 따라 달라진다. 상단 칩은 시스템 글꼴과 크기를 따르며, 집중·일시정지·휴식 아이콘을 구분한다. 알림에서
일시정지·계속하기·집중 마치기·휴식 건너뛰기를 할 수 있다.
일시정지 상태는 남은 시간을 고정하고, 오프라인에서는 실시간 표시와 조작을 멈춘다.
활성 세션이 있으면 알림이 있는 서비스를 통해 앱 화면 밖에서도 동기화를 유지한다.
앱을 강제 종료하거나 폰을 재시작한 뒤에는 앱을 다시 열어 연결한다.

- 접힌 화면: 한 손 조작용 한 칼럼.
- 펼친 화면: 타이머와 오늘 기록을 나란히.
- 가로 반접힘: 위쪽 타이머, 아래쪽 조작과 기록.
- 접기·펼치기·회전: 타이머 연결과 화면 선택값을 유지.

## 시계와 시간 설정

타이머 오른쪽에서 **오빗 링 / 모래시계**를 선택한다. 두 모양 모두 60분 기준이며
선택은 기기별로 저장된다. 반접힘 화면에서는 아래쪽 조작 영역에서 선택한다.

시계 근처의 **시간 설정**에서는 다음 값을 분리해 변경한다.

- **이번 목표 저장**: 일시정지된 카운트다운의 경과 시간을 유지하고 전체 목표만 변경
- **기본 시간 저장**: 새 집중과 다음 자동 휴식부터 적용할 주제 기본값 변경

실행 중 카운트다운은 먼저 일시정지해야 이번 목표를 변경할 수 있다. 새 목표는
이미 지난 시간보다 길어야 한다.

## 개발용 실행

README의 독립 MySQL과 `scripts/dev.py` 실행 방법을 따른다.
`.local/dev.json`과 `.local/production.json`은 모두 Git에서 제외한다.

개인용 debug 설치 자동화가 필요하면 `.local/production.json`에 서버 주소와
연결 키를 보관하고 `scripts/android_acceptance.py install`을 사용한다.
debug 앱은 계측용 임시 연결 파일을 한 번 읽고 Android Keystore에 저장한 뒤
삭제한다. release 앱은 이 경로를 읽지 않는다.

분·초 숫자는 읽기와 조절 상태에서 같은 글꼴 크기와 간격을 사용한다.
숫자를 누르거나 창의 초점을 바꿔도 배치가 바뀌지 않는다. 멈춘 세션에서 변경 가능한
남은 시간이 줄어들어도 집중·휴식 단계의 글꼴 크기 기준은 유지한다.

글꼴 크기는 단계의 최대 시간을 기준으로 유지하되, 위치는 실제로 보이는 분·초 전체를 기준으로 가운데 맞춘다. 두 자리 분 앞에 세 자리 분용 빈 칸을 남기지 않는다.

## 종료 알림

집중 카운트다운이 끝나면 **집중을 마쳤어요**, 짧은·긴 휴식이 끝나면
**휴식이 끝났어요** 알림을 보낸다. 시스템 기본 소리·진동 설정을 사용한다.
수동 마치기·휴식 건너뛰기·스톱워치는 자연 종료 알림을 만들지 않는다.
일시정지·시간 변경·오프라인에서는 이전 예약을 취소하며, 재연결 때 지난 알림을
몰아서 다시 보내지 않는다. 확인할 수 없는 오프라인 종료는 알리지 않는다.

상단 동기화 배지를 누른 뒤 **알림 테스트**로 타이머와 기록을 바꾸지 않고
알림을 확인할 수 있다. 소리·배너·방해 금지·디스플레이 잠자기 알림 여부는
각 기기의 시스템 설정을 따른다.

Mac은 패키징된 `Stint.app`의 시스템 알림 센터를 사용한다. 창을 닫아 메뉴바에
남겨두면 계속 예약하지만 앱을 완전히 종료하면 이전 예약을 취소한다.
네이티브 연동 빌드에는 Xcode Command Line Tools의 `xcrun clang`이 필요하다.

Android는 조용한 진행 중 채널과 별도로 **타이머 종료** 채널을 사용한다.
정확한 타이머 예약이 가능하면 시스템에 다음 알람 표시가 나타날 수 있다.
Android 12에서는 정확 알람 권한 상태에 따라 예약이 지연될 수 있다.
강제 종료나 재부팅 후에는 앱을 다시 열어 동기화한다.
